# velos-api - Projet DevOps

Projet réalisé dans le cadre du TP DevOps autour d'une API Flask, avec Docker, Docker Compose, Kubernetes et Jenkins.

## Rendu final

> **La branche à consulter pour la version finale et complète du projet est `docs/rendu-final`.**

La branche `main` a été utilisée comme branche principale tout au long du projet et est protégée par des règles GitHub. Les différentes évolutions ont été intégrées à travers des branches et des Pull Requests.

Afin de conserver l'historique du travail et de présenter le rendu final de manière propre, celui-ci est disponible sur la branche :

```text
docs/rendu-final
```

Cette branche contient notamment :

- le rapport final ;
- les 24 captures demandées ;
- le QCM et la documentation ;
- les fichiers Docker, Kubernetes et Jenkins ;
- le code et les tests de l'API ;
- un `README.md` détaillé servant de guide pour comprendre l'organisation du dépôt, son architecture, les différentes branches et la chaîne CI/CD.

## Où commencer ?

1. Sélectionner la branche **`docs/rendu-final`** sur GitHub.
2. Consulter son **README.md** pour une présentation complète du projet.
3. Consulter **RAPPORT.md** pour le détail des différents jalons et des preuves réalisées.
